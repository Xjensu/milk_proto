# Internal engineering records

This directory contains technical records that support maintenance and release decisions. It has no protocol authority unless a document explicitly points to a normative source under `docs/spec/`.

- `handoff/`: current implementation state and next integration steps.
- `decisions/`: unresolved or resolved protocol decisions.
- `audits/`: security, lifecycle, and design findings.
- `conformance/`: wire and implementation discrepancies.
- `release-evidence/`: inventories, test results, and this documentation reboot report.

The classification used during the reboot is recorded in
[`release-evidence/repository-inventory.md`](release-evidence/repository-inventory.md).

Records use neutral technical language. They contain no prompts, model names, or workflow instructions.
