# Public UI refinement, 2026-09-30

The second refinement reduces visual weight while preserving the sparse public directory and existing desktop identity. Mobile home navigation now reads horizontally, with velvet floor numbers and fine neutral rules. Faculty selection carries its monogram into the detail view through a transform/opacity animation. Week selectors use underlines; timetable geometry and all columns remain intact within labelled, keyboard-scrollable regions. Teacher profiles use quieter typography and a neutral SVG portrait area. Russian product copy is preserved.

## Runtime verification

The production schedule_web container was rebuilt and restarted. SHA-256 values for the new public stylesheet and faculty controller match the workspace files. Rails eager loading, helper syntax and whitespace checks pass.

Regular Chromium Playwright was used after the available Playwright MCP failed to launch its Firefox profile. Ten signed-out routes were checked at 320, 390, 768 and 1440 pixels: home, faculty catalogue, faculty detail, teacher catalogue, teacher profile, room catalogue, occupancy, guide, group timetable and missing-selection state. All 40 checks report no document overflow or page errors. Fifteen interaction checks pass, including faculty/course/group selection, timetable scrolling, lesson dialogs, week persistence, date selection, teacher search, guide navigation, sign-in dialog focus restoration and reduced-motion navigation. No new test files were added to the repository. Authentication-gated room detail and password pages were not visually verified.

Visual assessment: the refined screens have a calmer hierarchy and more usable mobile spacing. The faculty monogram transition provides the distinctive interaction without adding decorative content. Generated imagery informed the composition; fabricated teacher photographs were not introduced.
