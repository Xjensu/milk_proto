# Материалы аудита курса

Этот каталог фиксирует доказательную базу курса для ревизии, указанной в
[baseline.md](baseline.md). Следующие ссылки являются планируемыми выходами
аудита: их наличие не следует считать заявлением о завершённости.

- [baseline.md](baseline.md) — зафиксированная исходная ревизия.
- [spec-core.md](spec-core.md) — планируемый аудит ядра спецификации.
- [security-wire.md](security-wire.md) — планируемый аудит безопасности и wire-форматов.
- [performance-extensions.md](performance-extensions.md) — планируемый аудит производительности и расширений.
- [implementation.md](implementation.md) — планируемая классификация реализации.
- [traceability.csv](traceability.csv) — планируемая трассировка требований.
- [discrepancies.md](discrepancies.md) — планируемый журнал расхождений.
- [coverage.csv](coverage.csv) — планируемая матрица покрытия.

## Критерий завершения

Аудит завершён, когда прочитаны все 18 спецификаций и исследовательские
файлы, классифицированы все crate, все критичные для курса требования
сопоставлены либо помечены unmapped, а конфликты перенесены в
`discrepancies.md`.
